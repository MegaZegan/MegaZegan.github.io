Published GitHub ProjectSOC / Detection

SentinelForge

Defensive SOC analytics toolkit that normalizes logs, applies detection rules, scores risk, and generates HTML reports for analyst review.

  • Brute force, impossible travel, privilege escalation, IOC, probing, and exfiltration detections.
  • Python CLI, pytest coverage, sample telemetry, report generator.
github.com/MegaZegan/SentinelForge
Published GitHub ProjectCloud Security

CloudPolicyLens

IAM-style cloud policy linter for risky permissions, public principals, unbounded PassRole, broad NotAction, and missing guardrails.

  • Turns policy risk into explainable findings with remediation guidance.
  • Good fit for pull request reviews and least-privilege conversations.
github.com/MegaZegan/CloudPolicyLens
Published GitHub ProjectDevSecOps

SecretHawk

Local defensive secret scanner with regex checks, entropy scoring, masked findings, allowlist comments, JSON, and SARIF output.

  • Designed to catch secrets before they reach production.
  • SARIF output makes it CI and code-scanning friendly.
github.com/MegaZegan/SecretHawk

Network traffic triage concept for turning flow logs into suspicious-behavior summaries: unusual ports, volume spikes, beacon-like timing, and risky destinations.

  • Expandable into a Python CLI using CSV/Zeek-style logs.
